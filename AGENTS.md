# sprite_generate

Pixel-art / sprite-animation editor (spritepaint.com clone). Pure client-side Next.js App Router app — no backend, database, auth, API routes, or online sharing by design.

## Commands

- `npm run dev` — dev server
- `npm test` — Vitest run (all unit tests)
- `npx vitest run lib/canvas/drawing.test.ts` — single test file
- `npm run lint` — ESLint flat config (`eslint.config.mjs`)
- `npx tsc --noEmit` — typecheck (no npm script exists for this; run it directly)
- `npm run build` — production build

Verification order before committing: `npm run lint` → `npx tsc --noEmit` → `npm test`.

## Architecture (non-obvious)

- `lib/store/projectStore.ts` — single Zustand store: `Project` state (pixels/layers/frames) plus non-persisted UI state (active tool/color/zoom). Components only wire UI events to store actions.
- `lib/canvas/*` (drawing, compositing, zoomPan, transform) and `lib/file/*` (projectFile, exportPng, autosave) are pure, unit-testable functions — keep pixel logic here, not in components.
- `components/editor/*` — React UI shell; `Editor.tsx` is the root, mounted from `app/page.tsx`.
- Path alias `@/*` → repo root (`tsconfig.json`); tests still use relative imports.
- Product/scope source of truth: `docs/superpowers/specs/2026-09-08-sprite-editor-design.md`; implementation plan in `docs/superpowers/plans/`.

## Hard constraints (from spec — do not violate)

- `imageSmoothingEnabled = false` on every canvas context used for rendering or export.
- History is full-state snapshots, capped at 50 entries.
- Symmetry mirroring applies only to Pencil/Eraser/Line/Rectangle/Ellipse/Fill — never Eyedropper or Move/Lasso.
- Lasso scale is uniform only (no independent width/height handles).
- Autosave to `localStorage` every 5 minutes, only when `isDirty === true`; reset on export or Save Project.
- Export PNG/spritesheet preserves pixels 1:1, no scaling.
- No Next.js API routes, no external drawing/animation libraries.

## Testing

- Vitest + jsdom + Testing Library; `globals: true`, environment `jsdom`.
- Test include patterns: `lib/**/*.test.ts(x)`, `components/**/*.test.tsx` — tests live next to source.
- `vitest.setup.ts` polyfills `ImageData` from the `canvas` package — jsdom does not provide it; keep that polyfill working or pixel tests break.
- No E2E tests; canvas interactions are verified manually in-browser.
